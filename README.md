# campus-ai

Agentic AI products for higher education in BC, Canada and the EU.

| Product | What it does |
|---|---|
| Course Access Agent | Audits course materials (PDF, PPTX, DOCX) against WCAG 2.2, fixes what it can, and sends the rest to a human reviewer |
| Research Bridge | Matches BC researchers with EU partners and Horizon Europe calls, with evidence for every match |

The full design and 4-week build plan is in
[`docs/plans/master_plan.md`](docs/plans/master_plan.md).

Status: planning. Code starts with task card P0 (project skeleton).
